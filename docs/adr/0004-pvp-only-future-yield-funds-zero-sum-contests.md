# Tesoro is PvP-only: future yield funds zero-sum contests, not purchases

Gemas are claims on staking yield that hasn't accrued yet. In a head-to-head Match the payee is the winner, who can wait: they receive the loser's Gemas and redeem them as that yield lands, so nobody fronts money and no reserve or lender exists. In a purchase (shop items, API access, subscriptions) the payee is a merchant who must be paid now, so someone has to lend against the buyer's future yield — that is buy-now-pay-later credit, a market that already exists. Decided (Ailton, Oct 1, 2026): Tesoro stays PvP-only; Gemas are spent only on zero-sum contests between Players.

## Considered Options

- **Stake-to-access for software businesses** (gate API tiers by stake, meter calls, route revenue to stakers), suggested by Superteam Brasil leads: rejected — merchants need payment now, which turns the Advance into credit; revenue routing to stakers also reads as a security.
- **Pooled staking with one participant winning each period's rewards, with bids to boost odds**: rejected — an on-chain premium bond / no-loss lottery, tried repeatedly without lasting traction; paid odds make it a lottery.
